How to Connect Voice Invoice Agent to Your Existing Website

Integrating this agent into your existing web app (React, Next.js, Vue, Node.js, Django, or custom HTML) requires 3 simple steps:

1

Deepgram Speech-to-Text API Endpoint

Send recorded browser audio directly to the /api/transcribe endpoint.

// Client-side JavaScript Audio Recording
const mediaRecorder = new MediaRecorder(stream);
let audioChunks = [];
mediaRecorder.ondataavailable = e => audioChunks.push(e.data);

mediaRecorder.onstop = async () => {
    const audioBlob = new Blob(audioChunks, { type: 'audio/webm' });
    const formData = new FormData();
    formData.append('file', audioBlob, 'voice_command.webm');

    const res = await fetch('http://localhost:8000/api/transcribe', {
        method: 'POST',
        body: formData
    });
    const data = await res.json();
    console.log("Transcribed Text:", data.transcript);
};
2

CrewAI Agent Processing API

Pass the transcribed text to /api/process-invoice to trigger agent entity matching and tax validation.

const response = await fetch('http://localhost:8000/api/process-invoice', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ transcript: data.transcript })
});
const agentOutput = await response.json();
const draftInvoice = agentOutput.draft;
// Display draftInvoice on your website's modal or confirmation view
3

Human Confirmation API

When the user reviews and clicks "Confirm Invoice" on your UI, call /api/confirm-invoice to finalize stock update.

const confirmRes = await fetch('http://localhost:8000/api/confirm-invoice', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        invoice_id: draftInvoice.id,
        action: 'CONFIRM'
    })
});
const finalRecord = await confirmRes.json();
console.log("Invoice Confirmed & Stock Deducted!");
